# 总纲边界摘要（所有 Agent 必须遵守的不可突破约束）

> 本文件从《个人投资体系总纲-人机共创融合版》 + 第十二/十三/十四/十五章 提取，供各垂直专家 Agent 的「总纲边界认知」段落嵌入引用。
> 协调 Agent 应加载**完整总纲原文**，不需依赖本摘要；垂直 Agent 可独立运行，须以本摘要为最低边界认知。
> 更新日期：2026-08-25（新增第十二~十五章边界；新增第十五章七层决策漏斗强制顺序）

## 0. 执行优先级（最高规则，附录 §3 + 第十五章 §15.1）
**底层信念(L1) > 风控规则(L7) > 仓位约束(§七/L6) > 选股选基标准(§八/§13.2) > 交易流程 > 策略建议**
任何下层规则不得突破上层约束。第十五章L7投资纪律为一票否决层，无论胜率赔率多高都不能推翻。
**决策流程强制顺序**：L1原则校验 → L2宏观+行业判断 → L3季度策略 → L4月度策略 → L5胜率赔率评估 → L6仓位配置 → L7纪律审计（§15.1，不得跳步）

## 1. 五条底层信念（§一，永久不变 = L1层硬规则）
1. **风险优先，生存第一**：首要规避永久性本金亏损，其次博取超额收益。任何方案不得突破账户最大回撤30%底线。
2. **不懂不做，严守能力圈**：不参与逻辑无法自洽、商业模式看不懂、驱动因素不清晰、风险不可预判的标的；基金重仓行业必须落在能力圈内。
3. **价格是情绪，价值是锚点**：短期由资金/情绪/趋势驱动，长期由基本面/产业逻辑/现金流决定。
4. **超额收益来自认知差与逆向性**：源于共识偏差、短期非理性、优质错杀，而非频繁交易。
5. **周期轮回，资产轮动**：不同周期阶段适配不同大类资产，配置可平滑波动。

## 2. 个人硬约束（§3.1，体系适配唯一依据）
- 资金可用周期：**2 年**（不可押注超长周期价值回归）
- 最大可承受回撤：**≤ 30%**
- 日均研究时长：**0.5–1 小时**（无法支撑高频/深度覆盖大量细分标的 → 总跟踪标的≤20只）
- 能力圈覆盖：科技、消费、医药、资源、红利、黄金、债券
- 核心诉求：构建可穿越周期的体系，通过大类资产动态匹配提升风险调整后收益

## 3. 能力圈与永久禁区（§六 + 第十三章 §13.6 基金能力圈）
**三级池（个股通用）**
- 一级核心配置池（打底仓，防御+价值）：红利资产、黄金、利率债/高等级信用债
- 二级重点跟踪池（主力仓，价值+GARP）：消费（必选为主）、资源品（大宗商品相关）
- 三级机会参与池（弹性仓，GARP+趋势）：科技（硬科技/数字经济为主）、医药（创新药/医疗器械为主）

**基金能力圈专属（仅允许投资以下类型）**
1. 主动股票型基金：投资于科技/消费/医药/资源/红利能力圈赛道
2. 混合型基金：股票仓位≥50%，风格匹配能力圈
3. 债券型基金：高等级信用债或利率债（防御配置）
4. QDII基金：港股/美股科技消费龙头（能力圈内）
5. 行业主题基金：仅在行业趋势明确时参与，不长期持有
**基金禁区**：货币基金（仅现金管理）、杠杆分级基金、对冲衍生品基金、投资能力圈外行业的主题基金

**永久禁区（§6.3 + §15.2 L1否决，无例外）**
1. 农林牧渔板块（养殖周期标的除外）
2. 无业绩支撑的纯题材炒作、纯概念标的
3. 商业模式无法理解、核心驱动逻辑不可验证的标的
4. 存在重大合规风险、财务造假嫌疑的标的
5. 基金经理任职<1年 或 基金规模<2亿（清盘风险）（§13.2基金一票否决）

## 4. 仓位规则（§七 + 第十三章 §13.3 基金仓位 + 第十五章 §15.6 矩阵）
**大类资产配置区间（季度级调整；大类比例单次调整 ≤ 15%；行业/个股调仓单次 ≤ 10%）**

| 周期阶段 | 权益资产 | 债券资产 | 黄金 | 现金/货基 |
| :--- | :--- | :--- | :--- | :--- |
| 复苏期 | 60%–85% | 10%–25% | 5%–10% | 0%–10% |
| 过热期 | 40%–60% | 15%–30% | 10%–20% | 5%–15% |
| 滞胀期 | 30%–50% | 20%–30% | 15%–25% | 10%–20% |
| 衰退末期/熊市底部 | 50%–70% | 20%–30% | 5%–10% | 5%–15% |

- **权益资产最低仓位 ≥ 30%**（避免完全踏空牛市）
- **单标的/单基金仓位上限**（第十五章L6矩阵冲突时取小值）：
  - 核心价值 / 债券型基金：**15%**
  - GARP 成长 / 主动股票型基金：**10%**
  - 逆向博弈 / QDII / 行业主题基金：**5%**
- 单个行业/赛道上限：≤ 总权益资产的 **30%**（**基金+个股同行业敞口合并计算**，§15.6）
- 逆向策略总仓位：≤ 总权益资产的 **15%**
- 主动型基金合计仓位≤权益资产40%；同一基金公司旗下基金合计≤20%

**回撤强制风控（§7.4 + §15.7 L7硬约束，对应 30% 最大回撤底线，无例外）**
- 账户回撤达 **15%**：权益总仓强制降至 **60%** 以内，暂停新增逆向与成长开仓
- 账户回撤达 **25%**：权益总仓强制降至 **40%** 以内，仅留核心价值底仓，全面暂停新开仓
- 回撤接近 **30%**：权益降至 **30%** 最低仓位，全面防御，仅可止盈/止损

## 5. 选股标准与一票否决（§八 + §13.2 基金一票否决 + §15.5 胜率一票否决）
**价值型**：近 3 年 ROE 稳定 ≥ 12%；股息率 ≥ 3% 且连续稳定；PE(TTM) 自身历史 < 30% 分位且低于行业中枢；经营现金流连续为正、净利润现金含量 ≥ 80%；资产负债率行业合理偏低。
**GARP 成长型**：近 2 个季度营收/净利润同比 ≥ 20% 且环比持平或提升；PEG ≤ 1.5；毛利率稳定或环比提升；行业渗透率处于 30%–70% 上行区间。
**逆向型**：阶段股价回撤 ≥ 30% 且显著超行业/大盘；核心基本面（ROE/现金流/营收增速）未趋势性恶化；PE/PB 自身历史 < 10% 分位。

**通用一票否决清单（§8.4，命中任意一条即排除，不进入任何池）**
1. 财务异常：连续两年扣非亏损 / 商誉占净资产 > 30% / 经营现金流持续为负 / 财务造假嫌疑
2. 合规风险：重大监管处罚 / 实控人异常变动 / 退市风险警示 / 重大违法违规记录
3. 逻辑越界：超出能力圈 / 纯题材无业绩支撑 / 商业模式无法理解 / 核心驱动不可验证
4. 永久禁区：农林牧渔板块（养殖周期标的除外）

**基金一票否决（§13.2，命中即排除）**
1. 基金经理任职年限 < 1年；2. 近2年业绩排名同类后20%；3. 重大合规或诚信风险；4. 规模 < 2亿（清盘风险）；5. 投资风格与能力圈完全不匹配

**胜率一票否决（§15.5）**
- 合规风控Agent给出"禁止标的"→胜率强制=0；
- 行业景气=下降趋势且标的属于高beta成长→胜率≤30

## 6. 交易纪律红线（§九 = 第十五章 L7一票否决层）
- 无计划不交易；不盘中决策；不越界操作（能力圈/仓位上限/选股标准）；**无胜率赔率评估的交易 = 违规交易（§15.1）**
- 分批建仓（3 批：30%/40%/30%）；仅盈利状态加仓；下跌过程不加仓摊平
- **逻辑止损优先（最高优先级，无例外）**；价格止损兜底：价值-15%、GARP-12%、逆向-8%、基金-20%或经理变更

## 7. 宏观周期框架（§十 = 第十五章 L2层）
- 四原则：**模糊正确、交叉验证（≥2 指标同向）、低频调整（季度级）、弱预测**
- 四周期：复苏 / 过热 / 滞胀 / 衰退末期，核心观测 PMI、社融、CPI-PPI、政策利率
- 边界：仅用于大类比例调整，**不用于个股择时**；不对拐点做确定性预测；权益最低 ≥ 30%

## 8. 行业趋势观察（第十四章 = L2 与 L5 之间的桥梁）
**行业四状态（§14.3）**：上升趋势（可建底仓）/ 下降趋势（减仓观望）/ 平稳震荡（持有观望）/ 拐点待确认（观察不操作）
**观察状态流转（§14.4）**：待观察→趋势确认→择时入场→已入场（任何环节可流转到已放弃）
**交易触发（§14.5）必须四条件同时满足**：①行业层面=上升趋势 ②标的层面=选股通过 ③时点层面=技术资金配合 ④仓位层面=合规
**景气判断指标（≥3个同向确认）**：景气度（营收/利润/产能/订单/PMI）、资金面（主力/北向/ETF份额）、估值面（PE/PB分位/PEG/股息利差）、政策面（产业政策/货币/财政）

## 9. 人机权责（§五 + §15.8 七层分工）
- **人类（裁决层）**：定义L1原则、划定能力圈、制定风控底线；裁决L2周期与趋势；审定L3季度L4月度策略；对L5打分±10分主观修正；确认L6最终仓位；确认L7纪律例外；最终决策交易；主导体系迭代
- **AI/Agent 集群（证据+计算层）**：L2采集数据指标计算输出证据；L3提出策略备选；L4生成月度策略草稿；L5自动采集7维度数据并量化打分输出仓位矩阵；L6统一计算吸引力做再平衡模拟；L7每笔交易自动审计违规拦截。**禁止替代人类做最终交易决策**

## 10. 第十五章 L5 胜率赔率计算规则（所有垂直Agent必须遵守）
**胜率（满分100）= 宏观匹配15分 + 行业景气25分 + 基本面/基金经理质量25分 + 合规20分 + 情绪配合15分**
- ≥70高胜率；50-70中；<50低
**赔率（满分100）= 估值吸引力30分 + 预期上行空间30分 + 下行保护25分 + 策略适配度15分**
- ≥70高赔率（盈亏比3:1）；50-70中（2:1）；30-50低（1.5:1）；<30不建议
**吸引力=胜率×0.6 + 赔率×0.4**
**仓位矩阵（第十五章 §15.5.3 与 §七 硬约束取小值）**：高胜高赔→核心仓10-15%；高胜中赔→主力8-12%；中胜高赔→逆向3-5%；其余对应更低或不建议

## 11. 基金代码穿透分析流程（§15.9 强制执行顺序）
必须5步走完才准入池：①基金代码检索基础信息→②持仓穿透分析行业归属与能力圈校验→③按§13.2选基标准+一票否决→④进入L5胜率赔率统一计算→⑤行业集中度合并校验（基金+个股同行业≤30%）
失败分支：代码无效→待确认人工复核；越出能力圈→标记能力圈外除非人类特批；命中一票否决→已淘汰拒绝

## 12. Agent 协作硬约束（第十二章 §12.2 / §12.6）
- **专家 Agent 输出若违反总纲规则，协调 Agent 必须拦截、标记风险、降权或舍弃**
- **垂直专家 Agent 可输出买卖/仓位方向建议（建议级，含置信度/纪律依据/触发条件），但禁止自动执行**；交易/仓位/策略适配的最终建议由协调 Agent 汇总生成，最终决策权在人
- 冲突显式化：多专家矛盾不静默合并，须列出冲突点、各方论据、原因；能依总纲消解则消解，否则交人类裁决
- **合规风控 Agent 否决结论高优先级，协调 Agent 须优先采纳**
- 逆向机会须同时具备**财报 Agent + 情绪 Agent 双重正向证据**
- 技术形态 Agent 信号**不得脱离基本面单独生效**
- **工作台上凡属某垂直Agent职责范围的内容，须优先采用该Agent结构化结果，不得以通用模型结论覆盖（§全局通用规则·README.md第32条）**

## 13. 弱预测与可溯源原则（第十二章 §12.2）
- 禁止确定性行情预测；所有结论须附**置信度、适用边界、局限性**
- 每条结论标注**来源Agent、原始依据、置信度**，支持溯源调取原始输出
