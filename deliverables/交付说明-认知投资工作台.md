## 七、在线部署（打开即用 · 纯网页版 + CloudStudio）

> **目标**：不再需要本机起服务、不再需要付费的 Railway。工作台已做成**纯前端网页**，部署到 CloudStudio 后直接得到一个分享链接，任何设备（手机 / 公司 / 家里）打开即用。数据通过 GitHub 私有仓库跨设备同步，AI 大脑由你的浏览器直连 DeepSeek。

### 架构（纯静态前端）
- 前端 `vite build` → `dist/` 静态产物（HTML/JS/CSS），**无后端服务器**
- 密钥存在**你自己的浏览器**（首次在「设置」页填一次，存 localStorage）
- 数据层：浏览器用你的 GitHub 令牌直连私有仓库 `investment-data`（运行数据）+ `investment-system`（体系知识）
- AI 大脑：浏览器用你的 DeepSeek 密钥直连 `api.deepseek.com`

### 已部署（v2.2.0）
- **分享链接**：由 CloudStudio 生成（见最新交付消息）
- 打开该链接即是用的工作台，无需安装、无需起服务

### 首次使用：填一次密钥（必做）
1. 打开分享链接 → 首页底部会提示「未连接云端：仅本地保存」
2. 点提示或左侧「设置」→ 填写两项：
   | 字段 | 去哪获取 | 说明 |
   |---|---|---|
   | GitHub Token | https://github.com/settings/tokens → Generate new token (classic)，勾 **repo** 权限 | 用于读写你的私有数据仓库，跨设备同步 |
   | DeepSeek API Key | https://platform.deepseek.com/api_keys → 创建 API key | 用于 AI 对话大脑 |
3. 保存后，状态提示变为「已连接云端」，此后自动从 GitHub 拉取 / 保存数据

### 打开即用验证
- 打开分享链接 → 看到首页全局看板
- 填好密钥后，「AI 对话」页发消息 → 浏览器直连 DeepSeek 回复
- 新增一条交易 / 复盘 → 自动写入 GitHub `investment-data` 私有仓库
- 换设备（手机/另一台电脑）打开同一链接、用同一 GitHub Token → 数据一致

> 不填 GitHub Token：功能照常，但数据只存本机浏览器（换设备不互通）。不填 DeepSeek Key：AI 对话不可用，其余正常。
