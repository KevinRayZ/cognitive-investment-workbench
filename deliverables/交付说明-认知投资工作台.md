## 七、在线部署（打开即用 · Railway）

> **目标**：不再需要本机双击 bat / 起服务。把工作台部署到 Railway 后，得到一个公网 URL，任何设备（手机 / 公司 / 家里）打开即用，数据通过 GitHub 私有仓库跨设备同步。

### 架构（单服务全栈）
- 前端 `vite build` → `dist/` 静态产物
- 后端 `server/index.js`（Express）**同源托管 `dist/` + 暴露 `/api`**，一个端口搞定
- 数据层：GitHub 私有仓库 `investment-data`（运行数据）+ `investment-system`（体系知识）
- AI 大脑：DeepSeek，Key 藏在服务器端（后端代理，浏览器看不到）

### 部署步骤（Railway）

1. **准备仓库**：代码已推送到 `KevinRayZ/cognitive-investment-workbench`（含 `railway.json` / `nixpacks.toml` / `package.json` 的 `build`+`start`）。
2. **Railway 新建项目** → 选择「Deploy from GitHub repo」→ 选该仓库。
3. **配置环境变量（关键！必须填 2 个）**，在 Railway 项目 Variables 面板：
   | 变量名 | 值 | 说明 |
   |---|---|---|
   | `DEEPSEEK_API_KEY` | `sk-...` | DeepSeek 平台获取：https://platform.deepseek.com |
   | `GITHUB_TOKEN` | `ghp_...` | 具备 **repo** 权限的 GitHub Token：https://github.com/settings/tokens （数据层读写私有仓库必须，服务端无 gh CLI 登录态） |
   | `NODE_ENV` | `production` | 可选，建议填 |
   > ⚠️ 不填 `GITHUB_TOKEN` → 交易/复盘/灵感等数据读写全部失败；不填 `DEEPSEEK_API_KEY` → AI 对话不可用（其余功能正常）。
4. **触发部署**：Railway 自动 `npm install && npm run build && npm start`，约 1-2 分钟。
5. **拿到 URL**：部署完成后 Railway 给一个 `xxx.up.railway.app` 公网地址。**打开它即是运行的工作台**。

### 打开即用验证
- 访问 `https://你的域名.up.railway.app/` → 看到首页全局看板
- 访问 `https://你的域名.up.railway.app/api/health` → 返回 `{"ok":true,...}`
- 任意子路由（如 `/chat`、`/trade`）刷新不 404（SPA fallback 已配）
- 在「AI 对话」页发消息 → 后端调 DeepSeek 回复（需 `DEEPSEEK_API_KEY` 已填）
- 新增一条交易 / 复盘 → 自动写入 GitHub `investment-data` 私有仓库（需 `GITHUB_TOKEN` 已填）

### 启用 AI 对话大脑（入口 A）
部署时把 `DEEPSEEK_API_KEY` 填入 Railway Variables 即可，无需本地改文件。填好后「AI 对话」页直接可用，与你在 WorkBuddy 的对话效果一致。
