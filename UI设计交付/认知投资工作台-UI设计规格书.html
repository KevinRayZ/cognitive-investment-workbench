2. 设计原则与边界红线

四条核心原则

  1. 人类最终负责：所有投资决策由人做出，AI 仅辅助。
  2. 可解释可追溯：每条结论须标注来源（原则 ID / 错误 ID / 数据出处）。
  3. 双向认知进化：人类写入记忆、AI 读取并建议，记忆回灌双环。
  4. 异常人工介入：AI 遇边界外请求必须暂停并交人工。

四条边界红线（不可逾越）

  • AI 无自主交易决策权：禁止自动下单、禁止替代人工确认。
  • 任何结论 须标注来源，禁止无根据断言。
  • 不做收益承诺，不暗示确定性。
  • 每个页面须含 「人类最终负责」声明（深色免责条）。
视觉实现要点：红线在第④屏被做成「视觉级断言」——页头红色徽章 + 整宽深色边界红线提示条 + 表格中边界外记录用 warn-soft 背景三重提示；其余各屏底部统一深色免责声明条。

4. 全局框架

每屏遵循统一骨架：TopBar（56px） → PageHeader（84px） → Main 内容区 → 免责声明条（52px）。左侧屏（②③④⑥⑧）在 Main 内采用 340px 列表 + fill 详情 双栏；右侧屏（①⑤⑦⑨）为单/多列自适应。

TopBar

左侧「认知投资工作台」品牌名（SemiBold）；右侧主导航 6 项：首页 / 备忘录 / 原则 / 交易 / 复盘 / 记忆（当前项高亮 primary）。高 56，白底，底边框。

PageHeader

左：面包屑（如「六层认知体系 / Layer ③」）+ 大标题 + 副标题；右：状态 pill（如「研究阶段·深度」/「AI 无交易决策权」）。高 84。

免责声明条

深色 #0F1729 底，左侧 amber 圆形「!」徽 + 白字「人类最终负责：本工作台所有投资决策由人做出，AI 仅作辅助，不越权、不承诺收益。」高 52。九屏统一。

图标规范：全程禁止 emoji。所有图标须用 SVG path 或「圆点 + 字符」实现（如状态圆点 8×8 圆角方块、警示用 amber 圆底白「!」字符）。圆点语义：红=认知/执行类错误、绿=启用/已验证、amber=草稿/心态类/待处理、灰=待验证/中性。

8. 导航与交互流程

8.1 六层导航

左侧栏 / TopBar 六项正确映射到对应屏：① 原则(③屏) · ② 策略(⑧屏) · ③ 研究(⑦屏) · ④ 交易(④屏) · ⑤ 复盘(⑥屏) · ⑥ 灵感(⑨屏)；首页(#①)为总览。

8.2 双环操作系统

  • 人类环 6 步（indigo）：观察 → 假设 → 录入备忘录 → 决策前闸门 → 执行 → 复盘写回。
  • AI 环 5 步（teal）：读取记忆 → 生成建议 → 标注来源 → 等待确认 → 回灌记忆。
  • 两环通过三层记忆衔接；AI 环不得跨过「执行/交易」环节。

8.3 决策前闸门（硬性）

备忘录提交前必须 5 步全通过：信息完整 → 风险评估 → 红队挑战 → 引用原则/错误 → 信心阈值。任一步 amber 未通过则阻塞提交，并提示人工复核。建议规则示例：TTM-PE 分位 > 80% 时信心上限压至 50%；三层估值中至少 2 层通过方可提交。

9. 开发交接说明

建议技术栈

  • 框架：React 18 + TypeScript（或 Vue 3），按屏拆分路由 / /memo /principle /trade /memory /review /research/:code /methods /inspiration。
  • 样式：Tailwind CSS，将 §3 令牌写入 tailwind.config 的 theme.extend（颜色、字体、圆角、间距）。
  • 字体：通过 @fontsource/noto-sans-sc 与 @fontsource/roboto-mono 引入，KPI/金额用 tabular-nums。
  • 图标：使用 lucide-react 等 SVG 图标库；严禁 emoji，状态圆点用 8×8 圆角方块 div。
  • 状态管理：原则/方法/错误/备忘录/记忆建议用 Zustand 或 Pinia 单 store，记忆层支持「人工写入 + AI 建议待确认」双态。

给开发智能体的硬性约束（来自边界红线）

  • 交易记录只能人工录入，AI 模块不得自动生成或替填交易行；边界外记录须人工复核后才能解除 warn 态。
  • 所有 AI 建议须带来源标注与「AI」角标，不得伪装成确定结论。
  • 红涨绿跌：涨/盈利/正向用 up #E5484D，跌/亏损/负向用 down #15803D（中国惯例，与美股相反）。
  • 每个页面渲染时强制包含底部「人类最终负责」声明条（深色 #0F1729）。
  • 决策前闸门为硬性阻塞逻辑，未全通过不得提交备忘录。
